Detailed Description

template<typename PAYLOAD_TYPE, typename Tree = FingerTree<Interval<PAYLOAD_TYPE>, IntervalMonoid, IntervalMeasure<PAYLOAD_TYPE>>>
class beman::fingertree::tree::FingerTreeIntervalIndex< PAYLOAD_TYPE, Tree >

Persistent interval index supporting stabbing and overlap queries.

Template Parameters
PAYLOAD_TYPEArbitrary data associated with each interval.
TreeBacking finger tree type (must use IntervalMonoid over IntervalMeasure). Default: FingerTree — correct at all sizes.

Complexity:

  • insert: O(1) amortized
  • query_point: O(log n + k) where k is the number of results
  • query_overlap: O(log n + k) where k is the number of results
  • entries: O(n)
