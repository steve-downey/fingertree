Detailed Description

template<typename T, typename Tree = FingerTree<T, PriorityMonoid<T>, PriorityMeasure<T>>>
class beman::fingertree::tree::FingerTreePriorityQueue< T, Tree >

Persistent double-ended priority queue backed by a finger tree.

Template Parameters
TElement type; must be totally ordered.
TreeBacking finger tree type (must use PriorityMonoid<T> over PriorityMeasure<T>). Default: FingerTree — correct at all sizes.

Complexity:

  • push: O(1) amortized
  • min / max: O(1)
  • pop_min / pop_max: O(log n)
  • size: O(1) — the count is the first component of the measure
  • to_vector: O(n)
