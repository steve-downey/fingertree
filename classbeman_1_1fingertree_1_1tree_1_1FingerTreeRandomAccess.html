Detailed Description

template<typename T, typename Tree = FingerTree<T, beman::fingertree::typeclass::sum_monoid<std::size_t>, UnitMeasure<T, std::size_t>>>
class beman::fingertree::tree::FingerTreeRandomAccess< T, Tree >

Persistent random-access sequence backed by a finger tree.

Template Parameters
TElement type.
TreeBacking finger tree type (must use a unit-count measure). Default: FingerTree<T> — correct at all sizes.

Complexity:

  • at / update / insert / erase: O(log n)
  • push_front / push_back: O(1) amortized
  • size / empty: O(1)
  • to_vector: O(n)
