Detailed Description

template<typename Tree = FingerTree5<std::string, std::size_t, RopeChunkMeasure>>
class beman::fingertree::tree::FingerTreeRope< Tree >

Persistent text buffer implemented as a rope over string chunks.

Template Parameters
TreeBacking finger tree type (must store std::string with a byte-count measure). Default: FingerTree5 — correct at all sizes. Pass FingerTree2<std::string, std::size_t, RopeChunkMeasure> explicitly if FT2 semantics are required.

Complexity:

  • from_text: O(n / chunk_size)
  • size_bytes: O(1)
  • to_string / chunks: O(n)
  • insert / erase / replace: O(log n)
