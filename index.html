Dependencies

Build Environment

This project requires at least the following to build:

  • A C++ compiler that conforms to the C++20 standard or greater
  • CMake 3.30 or later
  • (Test Only) GoogleTest

You can disable building tests by setting CMake option BEMAN_FINGERTREE_BUILD_TESTS to OFF when configuring the project.

Design notes

The implementation choices are documented under docs/:

  • Compile-time design — why the spine is a uniform type and a runtime variant rather than the textbook nested type, and the probe test that keeps it that way.
  • Allocator design — how structural sharing and the Lakos coherency rule are reconciled, and how the PMR layer stays zero-global-allocation.
  • Measure-based splitting — splitting on accumulated measures, the three split methods, and how the split walks the spine.

Integrate beman.fingertree into your project

Build

You can build fingertree using a CMake workflow preset:

cmake --workflow --preset gcc-release

To list available workflow presets, you can invoke:

cmake --list-presets=workflow

For details on building beman.fingertree without using a CMake preset, refer to the Contributing Guidelines.

Installation

Vcpkg

The preferred way to install fingertree is via vcpkg. To do so, after installing vcpkg itself, you need to add support for the Beman project's vcpkg registry by configuring a vcpkg-configuration.json file (which fingertree provides).

Then, simply run vcpkg install beman-fingertree.

Manual

To install beman.fingertree globally after building with the gcc-release preset, you can run:

sudo cmake --install build/gcc-release

Alternatively, to install to a prefix, for example /opt/beman, you can run:

sudo cmake --install build/gcc-release --prefix /opt/beman

This will generate the following directory structure:

CMake Configuration

If you installed beman.fingertree to a prefix, you can specify that prefix to your CMake project using CMAKE_PREFIX_PATH; for example, -DCMAKE_PREFIX_PATH=/opt/beman.

You need to bring in the beman.fingertree package to define the beman::fingertree CMake target:

find_package(beman.fingertree REQUIRED)

You will then need to add beman::fingertree to the link libraries of any libraries or executables that include beman.fingertree headers.

target_link_libraries(yourlib PUBLIC beman::fingertree)

Using beman.fingertree

To use beman.fingertree in your C++ project, include an appropriate beman.fingertree header from your source code.

{c++}
#include <beman/fingertree/fingertree.hpp>
