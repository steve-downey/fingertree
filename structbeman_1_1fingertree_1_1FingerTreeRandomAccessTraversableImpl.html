Detailed Description

template<class T, class Tree>
struct beman::fingertree::FingerTreeRandomAccessTraversableImpl< T, Tree >

Traversable typeclass implementation for FingerTreeRandomAccess<T, Tree>.

The result of traversal is always FingerTreeRandomAccess (using the default FT5-backed type for U), regardless of the source Tree parameter. This is the production-correct choice; callers who need a specific backing tree for traversal results can write their own adapter.
