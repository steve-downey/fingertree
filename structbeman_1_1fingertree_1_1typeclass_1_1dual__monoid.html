Detailed Description

template<class M>
struct beman::fingertree::typeclass::dual_monoid< M >

The dual of M: same value type, same identity, combine with its arguments flipped. If (T, ·, e) is a monoid then (T, ·ᵒᵖ, e) with a ·ᵒᵖ b = b · a is also a monoid.
