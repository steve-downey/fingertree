14// Traversable pattern invariants:
15// - Instances are single lookup objects that provide traverse(F, T).
16// - transpose is a derived object operation implemented from
17// traverse(identity).
18// - Dispatch happens through a provided object or
19// traversable_typeclass<Concrete>.
20// - Traversal must preserve container shape while transposing structure and
21// context.
